## Что это такое

**QuizMaster Constructor** — конструктор и ведущая платформа для двух классических
интеллектуальных игр:

- **«Кто хочет стать миллионером?»** — 15 вопросов, лестница сумм, несгораемые
  рубежи (5/10/15), подсказки «50/50», «Помощь зала» и «Звонок другу».
- **«Своя игра»** — табло с темами и стоимостями, раунды, «Кот в мешке»,
  «Аукцион», счёт команд.
- **«Угадай мелодию»** — четыре категории, растущий приз, торги с трёх–семи
  нот и суперигра на семь мелодий.
- **Классический квиз** — 7 раундов и 51 вопрос в формате паб-квиза: команды
  отправляют ответы с телефона, ведущий проверяет их и начисляет очки.

Автор создаёт игру, добавляет вопросы и запускает сессию. Игрокам **не нужен
аккаунт**: они открывают ссылку или вводят код комнаты, выбирают своё имя и
отвечают со своих телефонов.

## Что уже умеет

### Игры и сессии
- Создание игр четырёх форматов, редакторы вопросов и табло.
- Лобби с участниками, код комнаты и **QR-код** для входа.
- Ведущий управляет ходом с отдельного пульта.
- **Экран для проектора** (`/screen/:sessionId`): вопрос, варианты, табло,
  лестница и счёт в реальном времени — без кнопок управления.
- Игроки отвечают с устройств; есть режим, когда ответ фиксирует ведущий.
- **Таймер вопроса** с обратным отсчётом на пульте, экране и телефоне.
- **Медиа-вопросы с загрузкой файлов**: картинка сжимается в браузере до
  1400 px, аудио хранится как фрагмент до 600 КБ. Можно и просто вставить ссылку.
- **«Угадай мелодию»**: четыре тура, растущий приз, штрафные пропуски,
  выбывание после второго тура, торги и суперигра с таймером.
- **Классический квиз**: разминка, бинго, медиа, блиц, «За кулисами», пары
  и казино со ставками; команды отвечают с телефона, ведущий проверяет ответы
  и очки считаются автоматически.
- Тематические паки: кино, музыка, история, география, наука, литература,
  аниме, авто и другие.
- Итоги и рейтинг после игры.

### Платформа
- Аккаунты только для авторов; игроки — по коду комнаты и токену участника.
- Мобильный веб-интерфейс, PWA-манifest, service worker и офлайн-шелл.
- OG-теги и картинка для красивого превью ссылки в мессенджерах.
- Настольная стилистика сайта и классические ТВ-стили самих игр.

## Как это работает

1. Автор входит в кабинет и создаёт игру.
2. Добавляет вопросы (текст, варианты, правильный ответ, картинку/аудио).
3. Нажимает «Провести» — создаётся сессия с кодом комнаты.
4. Игроки заходят по коду или QR, выбирают имя и отвечают.
5. Ведущий вскрывает ответ; на проекторе идёт отдельный экран со счётом.

## Технологии

- **Frontend:** Vite 4, React 18, TypeScript, React Router.
- **Backend:** Firebase Auth (авторы) + Cloud Firestore (Spark, без Cloud Functions).
- **Медиа:** сжатие картинок в браузере и хранение файлов в коллекции `media`
  (Firestore), без Cloud Storage и биллинга.
- **Realtime:** Firestore `onSnapshot` для сессий, участников и ответов.
- **Хостинг:** GitHub Pages, публикация через GitHub Actions.
- **Безопасность:** Firestore Security Rules + токены участников.

## Безопасность

- Вопросы с правильными ответами читает **только автор игры**.
- Игроки не проходят Firebase Auth: получают сессию по коду и закрепляют имя
  одноразовым токеном.
- Ответы принимаются только с валидным токеном; читает их только ведущий.
- Менять сессию, счёт и участников может только ведущий.
- Медиатека (`media`): читать может любой участник и экран, загружать и удалять —
  только автор файла; листинг закрыт.
- Правила проверяются скриптом: `npm run test:rules` (27 проверок).

## Локальный запуск

```powershell
npm install
npm run dev -w packages/web
# http://localhost:5173/QuizMaster/
```

Сборка:

```powershell
npm run build -w packages/shared
npm run build -w packages/web
```

Тесты:

```powershell
npm run test:unit    # unit-тесты игровой логики
npm run test:rules   # сквозная проверка Firestore Rules
```

## Деплой

- **Фронтенд:** автоматически через GitHub Actions при push в `master`
  (публикация в ветку `gh-pages`).
- **Правила Firestore:** `firebase deploy --only firestore`.

## Структура

```
packages/shared   типы и игровая логика + unit-тесты
packages/web      React SPA
scripts           security-тест Firestore Rules
firestore.rules   правила безопасности
```
